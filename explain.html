How it works

The input is split on whitespace, respecting quotes, and then split again on unquoted pipes. The first token of each segment is looked up as a program, and the remaining tokens are classified as flags, arguments, URLs, paths, or permission modes.

  • Programs and their flags live in data/commands.json.
  • Combined short flags such as -xzvf are expanded into their individual flags when every letter is known.
  • Numeric modes passed to chmod are decoded into owner, group, and other permissions.
  • A small set of destructive patterns triggers a warning before you copy anything.

Coverage

The dictionary covers the commands used in the entries on this site. If a program or flag is missing, the explainer labels it as unknown rather than guessing. That is intentional: a wrong explanation is worse than no explanation.

Adding a command

Add a program and its flags to data/commands.json, then run python scripts/build_bundle.py. The format is documented on the contributing page.
