About CmdBook

A reference for commands and flags, written for people who are still learning them.

Purpose

CmdBook is a command reference for beginners. Most cheat sheets list commands and assume the flags already make sense. Each entry here explains what the command does, when you would use it, and what every flag changes. Commands that can delete data or expose a system are marked before you copy them.

The reference covers Linux, Git, Python, security, and web commands. The explainer uses the same dictionary to break down a command you paste, token by token, and it says when it does not recognise a program or flag instead of guessing.

Creator

CmdBook is built and maintained by @arovex.

Contributing

Entries live in data/<topic>.json. To add or correct a command, edit the matching topic file, add any new program or flag to data/commands.json, then run python scripts/build_bundle.py and python scripts/build_bundle.py --check.

Keep plain focused on what the command does, use when for the situation that makes you reach for it, and mark destructive commands as danger.
